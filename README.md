# LISAcube-3D
I have a tungsten analogue of the test mass at the heart of the LISA Pathfinder and LISA gravitational reference sensor (GRS). This repository collects 3D modeling work of the cube based on technical information we can find online. Repository contains reference images we used.

Models are used for 3D printing and visualization.

Folder names are by author who built those models.

## shane folder
Nested in this folder are three other folders:
- TestMassModel: files suitable for 3d printing the Cube (*.step, *.3mf, and *.stl)
- TestMassDisplay: files suitable for 3d printing a display stand for the Cube (*.step, *.3mf, and *.stl)
- TestMassLego: stud.io file for making a Lego LISA Cube (*.io for stud.io modelling)
